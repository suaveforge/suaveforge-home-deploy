로그인 버튼을 눌렀는데, 가입한 건지 알 수 없었다

사전 회원가입 없이 Google 로그인 뒤 서비스에 들어왔지만, 새 계정이 만들어진 건지 기존 계정에 연결된 건지 화면에서는 알 수 없었다.

2026년 8월 27일Cases

회원가입을 따로 한 적이 없었다. Google 로그인 버튼을 눌렀다. 서비스 안으로 들어왔다.

사용자 입장에서는 지금 로그인만 된 건지, 처음 가입까지 된 건지 알 수 없었다.

화면에서 알 수 있는 건 로그인 뒤 서비스 안으로 들어왔다는 사실뿐이었다. 새 계정이 만들어졌는지, 기존 계정에 연결됐는지는 보이지 않았다.

자동 가입 자체가 문제는 아니다

첫 소셜 로그인 때 자동으로 회원가입 처리하는 정책도 가능하다. 중요한 것은 실제 처리 결과가 일관되고, 사용자가 자신의 계정 상태를 필요한 만큼 알 수 있게 하는 것이다.

문구가 꼭 같을 필요는 없다. 실제 정책과 실제 처리 결과가 화면에서 모순 없이 읽히면 된다.

로그인 과정이 짧아도 계정 상태는 분명해야 한다

소셜 로그인이 짧은 흐름이어도 계정이 새로 만들어졌는지, 기존 계정과 연결됐는지, 문제가 생겼을 때 어떻게 복구하는지는 분명히 알 수 있어야 한다.
