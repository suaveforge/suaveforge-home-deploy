마지막 항목을 지운 뒤 화면이 이전 페이지 번호에 남았다

한 페이지의 마지막 항목을 삭제하자 전체 페이지 수는 줄었지만 화면은 이전 페이지 번호에 그대로 남았다. 화면에는 빈 목록이 표시됐다.

한 페이지에 항목 하나만 남아 있었다. 그 항목을 삭제했다.

전체 페이지 수는 줄었지만 화면은 삭제 전 페이지 번호에 그대로 남았다. 전체 페이지 수가 줄어 그 번호에 해당하는 페이지는 더 이상 없었고, 목록에는 아무 항목도 보이지 않았다.

현재 페이지의 마지막 항목 삭제
전체 페이지 수 감소
화면은 삭제 전 페이지 번호 유지
빈 목록 표시

삭제 뒤 페이지 위치가 갱신되지 않았다

삭제 자체는 끝났다. 문제는 데이터가 줄어든 뒤에도 화면이 더 이상 존재하지 않는 페이지를 계속 가리킨 데 있었다.

마지막 항목을 지운 뒤에는 새 전체 건수와 페이지당 표시 개수로 전체 페이지 수를 다시 계산해야 한다. 현재 페이지 번호가 새 범위를 벗어났다면 남아 있는 마지막 페이지로 이동해야 한다. 결과가 하나도 없다면 빈 상태를 보여줘야 한다.
