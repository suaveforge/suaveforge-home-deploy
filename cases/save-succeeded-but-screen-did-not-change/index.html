저장 성공 메시지는 떴는데, 화면 상태는 거의 그대로였다

저장 성공 메시지는 나왔지만 화면 상태가 거의 그대로여서 사용자가 저장이 끝났는지 다시 판단해야 했다. 저장 완료 여부를 화면에서 분명히 알기 어려웠던 사례다.

2026년 8월 27일Cases

저장 작업 뒤 “저장되었습니다”라는 메시지는 나왔다.

하지만 화면 상태는 거의 그대로였다. 사용자는 저장이 끝난 건지 다시 판단해야 했다.

내용 수정
저장 실행
“저장되었습니다” 메시지
화면 상태 거의 그대로
저장 완료 여부를 다시 판단

성공 메시지만으로는 완료를 판단하기 어려웠다

화면만으로는 실제 저장 결과가 반영됐는지 알기 어려웠다. 성공 메시지와 저장 뒤 상태가 서로 같은 결론을 보여줘야 사용자가 같은 작업을 다시 할지 고민하지 않는다.

저장이 완료됐다면 저장됨 상태, 마지막 저장 시각, 변경사항 없음처럼 결과를 확인할 수 있는 신호를 보여줄 수 있다. 반대로 저장이 끝나지 않았다면 성공 메시지를 먼저 보여주지 않아야 한다.
