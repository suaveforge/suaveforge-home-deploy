업로드 진행률 100%가 파일 처리가 끝났다는 뜻은 아니다

브라우저에서 파일 전송이 끝나도 서버에서는 압축 해제, 형식 검사, 미리보기 생성 같은 작업이 남아 있을 수 있다. 화면은 전송 완료와 실제 사용 가능 상태를 구분해서 보여줘야 한다.

사용자가 큰 파일을 올리면 화면에 진행률이 표시되는 경우가 많다. 이 숫자는 보통 브라우저에서 서버로 파일을 보내는 과정만 보여 준다.

파일 선택
   ↓
브라우저에서 서버로 전송
   ↓
전송률 100%
   ↓
서버 파일 검사
   ↓
필요한 후처리
   ↓
사용 가능

전송률이 100%가 된 직후 완료 화면으로 넘기면 사용자는 파일을 바로 쓸 수 있다고 생각한다. 하지만 서버에서 형식 검사나 압축 해제, 미리보기 생성이 남아 있으면 실제 기능은 아직 준비되지 않았을 수 있다.

후처리에 실패했을 때도 상태를 구분해야 한다. 전송은 끝났지만 파일 형식이 잘못됐거나 변환 작업이 실패했다면 단순히 업로드 성공이라고 표시하면 안 된다.

검수할 때는 진행률이 100%까지 올라가는지만 보지 않는다. 전송 뒤에 필요한 서버 작업이 끝났는지, 실패하면 어떤 상태가 보이는지, 완료 뒤 실제로 파일을 열거나 사용할 수 있는지까지 확인해야 한다.

업로드 완료는 바이트 전송이 끝난 시점보다 사용자가 파일을 쓸 수 있게 된 시점에 가깝다.
