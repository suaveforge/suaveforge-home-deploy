필터 초기화 버튼이 있어도 검색 조건이 남으면 초기화가 아니다

화면에서 입력값이 사라져도 URL이나 다음 검색 요청에 이전 조건이 남아 있으면 초기화가 끝난 것이 아니다. 버튼을 누른 뒤에는 필터를 적용하지 않은 목록이 다시 나와야 한다.

관리자 목록에는 기간, 상태, 담당자처럼 여러 필터가 붙는다. 초기화 버튼을 눌러 입력칸이 비어도 실제 검색 조건이 남아 있으면 초기화가 제대로 된 것이 아니다.

예를 들어 상태를 ‘처리 중’으로 고르고 검색한 뒤 초기화를 눌렀다고 하자. 화면의 선택값은 없어졌는데 URL이나 다음 검색 요청에 status=pending이 남아 있으면 목록에는 계속 처리 중인 항목만 나올 수 있다. 사용자는 필터가 비어 있는데 결과가 왜 그대로인지 알기 어렵다.

   ↓

   ↓

   ↓

   ↓

   ↓

   ↓
필터를 적용하지 않은 목록을 다시 조회

초기화할 때 페이지 번호와 정렬 기준까지 되돌릴지도 미리 정해야 한다. 같은 초기화 버튼이 화면마다 다르게 동작하면 무엇이 초기화되는지 예측하기 어렵다.

검수할 때는 버튼과 입력칸만 보면 부족하다. 브라우저가 서버로 보내는 검색 요청에서 이전 조건이 빠졌는지 확인한다. 필터를 적용하지 않은 목록이 다시 나오는지도 본다. 페이지 번호와 정렬 기준까지 초기화하기로 했다면 실제로 함께 바뀌는지도 확인한다.

초기화는 화면을 비우는 데서 끝나지 않는다. 버튼을 누른 뒤 사용자가 새 조건을 고르고 다시 검색할 수 있어야 한다.
