완료 메시지가 떠도 문의가 접수된 것은 아니다

사용자가 문의를 보내고 완료 메시지를 봤더라도 서버에 저장되지 않았다면 접수된 게 아니다. 화면을 다시 열었을 때 보낸 문의가 남아 있어야 한다. 관리자 화면에서도 같은 문의가 조회돼야 한다.

임시 검수 페이지Run 108

문의 화면을 점검할 때는 전송 버튼이 실제로 동작하는지와 완료 메시지가 뜨는지만 확인해서는 안 된다. 문의를 보낸 뒤 목록을 다시 열어 방금 보낸 내용이 남아 있는지 확인한다.

문의 작성
        ↓
전송 버튼 클릭
        ↓
완료 메시지가 뜨는가?
   아니오 → 전송 처리 점검
   예
        ↓
문의 내역에 방금 보낸 문의가 보이는가?
   아니오 → 저장 처리 점검
   예
        ↓
관리자 화면에서도 같은 문의를 볼 수 있는가?
   아니오 → 관리자 조회·권한 점검
   예 → 접수 완료

화면에는 완료 메시지가 떠도 서버에 문의가 저장되지 않을 수 있다. 화면을 다시 열었을 때 문의가 없다면 사용자는 같은 내용을 다시 보낼 수 있다. 반대로 서버에는 저장됐지만 관리자 화면에서 조회되지 않으면 담당자는 접수된 문의를 놓칠 수 있다.

그래서 완료 메시지만 확인해서는 부족하다. 문의가 서버에 저장돼야 하고 관리자 화면에서도 조회돼야 한다. 저장이나 조회 중 하나라도 실패하면 접수 완료라고 표시하면 안 된다.
