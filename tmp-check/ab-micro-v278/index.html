전송 완료가 떠도 문의가 접수된 것은 아니다

사용자가 문의를 보내고 완료 메시지를 봤더라도 서버에 저장되지 않았다면 접수된 것이 아니다. 화면을 다시 열었을 때 보낸 문의가 남아 있는지도 확인해야 한다.

v2.7.8 + micro detectorRun 105

문의 화면을 점검할 때는 전송 버튼과 완료 문구만 보면 안 된다. 문의를 보낸 뒤 목록을 다시 열고 방금 보낸 내용이 남아 있는지 확인한다.

문의 작성
        ↓
전송 버튼 클릭
        ↓
완료 메시지가 표시되는가?
   아니오 → 전송 처리 점검
   예
        ↓
문의 내역에 방금 보낸 문의가 보이는가?
   아니오 → 저장 처리 점검
   예
        ↓
관리자 화면에서도 같은 문의를 볼 수 있는가?
   아니오 → 관리자 조회·권한 점검
   예 → 접수 완료

화면에는 완료라고 나오더라도 서버에 문의가 저장되지 않을 수 있다. 화면을 다시 열었을 때 문의가 없다면 사용자는 같은 내용을 다시 보낼 수 있다. 반대로 서버에는 저장됐지만 관리자 화면에 보이지 않으면 담당자는 접수된 문의를 놓칠 수 있다.

점검할 때는 화면 표시, 서버 저장 상태, 관리자 조회 결과가 서로 맞는지 확인해야 한다. 어느 하나라도 다르면 접수 완료라고 표시하면 안 된다.

문의 접수가 끝났다면 사용자가 보낸 문의를 다시 확인할 수 있어야 하고 관리자도 같은 문의를 볼 수 있어야 한다.
