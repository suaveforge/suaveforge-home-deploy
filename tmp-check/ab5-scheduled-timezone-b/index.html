예약 발송은 사용자가 선택한 시간대를 기준으로 실행돼야 한다

한국에서 오후 3시로 예약한 알림을 UTC 15:00으로 그대로 저장하면 한국에서는 자정에 발송된다. 예약 기능은 사용자가 선택한 시각과 시간대를 함께 기준으로 삼아야 한다.

예약 메일이나 알림은 화면에서 시각 하나를 고르는 것처럼 보이지만 실제로는 시간대까지 함께 처리해야 한다. 같은 오후 3시라도 서울과 뉴욕에서는 서로 다른 순간을 가리킨다.

사용자가 15:00 선택
   ↓
사용자의 시간대 확인
   ↓
서버가 저장할 기준 시각으로 변환
   ↓
변환한 시각에 맞춰 발송

화면에서 받은 15:00을 서버가 사용하는 시간대의 15:00으로 그대로 저장하면 발송 시간이 달라질 수 있다. 예를 들어 서버가 UTC를 쓰는데 한국 사용자의 15:00을 UTC 15:00으로 저장하면 한국에서는 자정에 발송된다.

사용자가 계정의 시간대를 바꾸는 경우도 기준을 정해야 한다. 예약을 만들 때 선택한 시간대를 유지할지, 바뀐 시간대에 맞춰 예약 시각도 바꿀지 기능의 목적에 따라 결정한다.

검수할 때는 화면에 표시된 예약 시각과 실제 발송 시각을 함께 확인한다. 시간대가 다른 테스트 계정에서도 사용자가 선택한 시간대의 시각에 맞춰 발송되는지 확인해야 한다.

예약 기능은 사용자가 선택한 시각이 실제 발송 시각과 맞도록 처리해야 한다.
