업로드 100%는 파일 전송이 끝났다는 뜻이지 모든 처리가 끝났다는 뜻은 아니다

브라우저가 파일을 모두 보낸 뒤에도 서버에서는 형식 검사, 압축 해제, 미리보기 생성 같은 작업이 남을 수 있다. 화면은 파일 전송 완료와 실제 사용 가능 상태를 나눠 보여줘야 한다.

사용자가 큰 파일을 올리면 화면에 진행률이 표시되는 경우가 많다. 이 숫자는 대개 브라우저가 서버로 파일을 보내는 진행 상태를 뜻한다.

파일 선택
   ↓
브라우저가 서버로 파일 전송
   ↓
전송률 100%
   ↓
서버에서 형식 검사·압축 해제 등 필요한 작업 수행
   ↓
모든 작업 성공
   ↓
파일 사용 가능

전송률이 100%가 되자마자 완료라고 표시하면 사용자는 파일을 바로 쓸 수 있다고 생각한다. 서버에서 형식 검사나 압축 해제, 미리보기 생성이 진행 중이라면 파일은 아직 사용할 수 없는 상태일 수 있다.

서버 작업이 실패했을 때도 전송 성공과 구분해서 보여줘야 한다. 파일 전송은 끝났더라도 형식이 잘못됐거나 변환 작업이 실패했다면 사용자가 실패 이유를 확인할 수 있어야 한다.

검수할 때는 진행률만 보지 않는다. 전송 뒤에 필요한 서버 작업이 끝났는지 확인한다. 실패 상태가 화면에 제대로 표시되는지도 본다. 완료라고 표시된 뒤 실제로 파일을 열거나 사용할 수 있는지도 확인한다.

사용자가 파일을 실제로 쓸 수 있는 상태가 됐을 때 완료라고 표시해야 한다.
