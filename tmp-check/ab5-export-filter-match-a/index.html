화면에서 걸어 둔 조건과 내려받은 파일의 조건이 다르면 안 된다

목록에서 날짜와 상태를 좁혀 20건만 보고 있는데 엑셀에는 전체 300건이 들어가면 사용자는 파일을 다시 걸러야 한다. 내보내기는 화면에 적용된 검색 조건과 정렬 기준이 어디까지 반영되는지 분명해야 한다.

관리자 목록에서 검색한 뒤 엑셀이나 CSV를 내려받는 기능은 자주 쓰인다. 버튼이 현재 목록 화면 안에 있으니 사용자는 보이는 조건이 그대로 적용될 거라고 생각하기 쉽다.

화면에서 필터 설정
   ↓
목록 20건 조회
   ↓
엑셀 다운로드
   ↓
현재 검색 조건을 서버에 전달
   ↓
같은 조건으로 파일 생성

문제는 화면과 파일이 서로 다른 기준으로 데이터를 가져올 때 생긴다. 예를 들어 화면에서는 이번 달의 완료 주문만 20건 보이는데 파일에는 전체 주문 300건이 들어갈 수 있다.

필터는 적용되는데 정렬 기준은 빠질 수도 있다. 화면에서 최신순으로 보고 있다면 파일도 같은 순서를 따라야 하는지, 아니면 파일은 별도 기준으로 정렬하는지 서비스 안에서 기준을 정해 둬야 한다.

다운로드 기능을 검수할 때는 파일이 만들어지는지만 보면 부족하다. 화면에 걸린 조건과 파일 안의 데이터가 같은 범위를 가리키는지 확인해야 한다. 파일의 행 개수와 대표 항목도 함께 비교하면 빠진 조건을 찾기 쉽다.

내보내기는 화면에서 하던 작업을 파일로 이어 가는 기능이다. 사용자가 다시 필터링하지 않아도 될 만큼 같은 조건이 유지돼야 한다.
