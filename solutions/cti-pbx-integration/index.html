자주 묻는 질문

CTI·PBX 연동 개발 작업 범위는 어디까지인가요?

SuaveForge는 Asterisk·AMI·WebSocket·WebRTC 통신 상태를 회원·상담사·관리자 웹 화면과 연결하고 통화 이벤트, 종료 원인과 운영 로그를 추적할 수 있게 구성합니다. 실제 범위는 현재 시스템, 데이터, 외부 연동과 배포 조건을 확인한 뒤 확정합니다.

기존 시스템이 있어도 CTI·PBX 연동 개발이 가능한가요?

가능합니다. 기존 자산을 먼저 확인하고 유지할 부분과 변경할 부분을 나눠 불필요한 전면 재개발을 피합니다.

CTI·PBX 연동 개발에서 먼저 확인할 것은 무엇인가요?

PBX·AMI·WebSocket 이벤트 연결, 상담사 수신·통화 상태 표시, CDR·종료 원인·운영 로그 항목을 먼저 확인하고 완료 기준과 실패·복구 조건까지 정합니다.

현재 화면·문서·코드·URL이 있다면
필요한 범위부터 나눌 수 있습니다.
