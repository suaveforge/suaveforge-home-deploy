자주 묻는 질문

엑셀과 폴더 작업도 자동화할 수 있나요?

가능합니다. 파일명 규칙, 폴더 이동, 엑셀 읽기·쓰기, PDF 생성·병합, 데이터 검증처럼 반복 규칙이 있는 작업을 자동화할 수 있습니다.

웹사이트에서 데이터를 수집하는 프로그램도 가능한가요?

공개적으로 접근 가능한 범위와 해당 서비스의 이용 조건을 지키는 전제에서 브라우저 자동화, API 연동, 데이터 수집·정리 도구를 개발할 수 있습니다.

예약 실행과 실패 로그도 넣을 수 있나요?

가능합니다. 정해진 시간 실행, 재시도, 처리 결과 로그, 실패 파일 분리와 운영자 확인 기능을 포함할 수 있습니다.
