다음 행동이 막혔을 때 먼저 확인할 것

가입, 취소, 삭제가 중간에 멈추면 남은 상태가 다음 행동을 잠글 수 있다. 정상 흐름만 보지 말고 중단·재진입·부분 실패 뒤에도 사용자가 계속 진행하거나 스스로 복구할 수 있는지 확인한다.

2026년 9월 2일Guides

정상 경로만 따라가면 중간 상태 문제는 잘 보이지 않는다. 사용자가 창을 닫거나, 취소가 대기 상태에 남거나, 삭제가 일부만 끝난 뒤 다시 들어왔을 때 다음 행동이 가능한지 확인해야 한다.

작업 시작
도중 중단·부분 실패
같은 계정·대상으로 재진입
다음 행동 시도
이전 상태 때문에 진행이 막히는지 확인

중간에 멈춘 뒤 다시 들어왔을 때는 세 가지가 중요하다.

  • 사용자 본인이 취소하거나 다시 시작할 수 있는가
  • 운영자 처리만 기다려야 한다면 그 사실과 다음 절차가 보이는가
  • 이미 생성된 계정·예약·설정값 때문에 같은 시도가 계속 막히지는 않는가

“다시 시도하세요”만으로는 부족할 수 있다. 이전 상태가 남아 있다면 이어하기·취소·초기화 중 적절한 복구 경로가 있어야 한다.
