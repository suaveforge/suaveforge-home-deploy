목록 데이터와 페이지 상태가 어긋나면 빈 화면과 오래된 행이 남는다

삭제나 필터로 결과 수가 줄었는데 페이지 번호나 화면의 행이 이전 상태로 남으면 빈 목록이 보이거나 이미 지운 행이 계속 표시될 수 있다. 데이터가 바뀐 뒤에는 전체 페이지 수를 새 전체 건수와 페이지당 표시 개수로 다시 계산한다. 현재 페이지 번호가 새 범위 안에 있는지 확인하고, 화면에 보이는 행은 새 조회 결과로 바꾼다.

목록에서 행을 지우거나 필터를 바꾸면 전체 건수와 페이지 수가 달라질 수 있다. 현재 페이지 번호가 새 범위 안에 있는지 다시 확인하고, 화면에 보이는 행은 새 결과로 바꿔야 한다.

실제 프로젝트에서는 한 페이지의 마지막 항목을 삭제한 뒤 전체 페이지 수가 줄었는데도 화면이 이전 페이지에 남아 빈 목록을 보여준 일이 있었다. 공개 이슈에서도 한 페이지의 항목을 모두 지운 뒤 빈 페이지가 남거나, 삭제 뒤 페이지 이동이 어긋나거나, 필터 결과가 줄었는데 높은 페이지 번호가 그대로 남은 사례가 보고됐다. 또 다른 사례에서는 삭제한 행이 페이지 데이터에 계속 남았다.

데이터만 갱신

전체 건수는 줄었지만 화면은 이전 페이지와 이전 행을 그대로 보여준다.

페이지 상태도 함께 갱신

전체 페이지 수를 새 전체 건수와 페이지당 표시 개수로 다시 계산한다. 현재 페이지 번호가 새 범위를 벗어나면 새 범위 안의 페이지로 옮긴다. 화면에 보이는 행도 새 결과에 맞춰 갱신한다.

데이터가 남아 있어도 빈 페이지가 보일 수 있다

실제 데이터가 남아 있어도 현재 페이지 번호가 새 전체 페이지 수보다 크면 화면은 비어 보일 수 있다. 반대로 데이터에서 행이 삭제됐는데 화면이 이전 페이지 결과를 계속 보여주면 지운 행이 남아 보일 수 있다.

삭제·필터·검색 조건 변경 뒤에는 먼저 전체 페이지 수를 새 전체 건수와 페이지당 표시 개수로 다시 계산한다. 현재 페이지 번호가 새 범위 안에 있는지 확인하고, 화면에 보이는 행을 최신 결과로 바꾼다. 이전·다음 버튼도 새 페이지 수와 현재 페이지 번호를 기준으로 표시해야 한다.
