반복 클릭·반복 제출

Chatwoot에서는 느린 네트워크에서 제출 버튼을 여러 번 눌렀다. Keycloak에서는 OTP 폼을 반복 제출했고, Shopware에서는 가입 폼을 두 번 제출했다.

Enter 한 번·GA4 설정

Fluent UI에서는 Enter 한 번으로 폼 제출이 두 번 실행됐다. Google Site Kit에서는 GA4 설정 중 웹 데이터 스트림 생성 요청이 두 번 실행됐다.

각 사례에서 확인된 현상은 다음과 같았다. Chatwoot에서는 클릭할 때마다 새 채팅 스레드가 생겼고 Shopware에서는 게스트 고객 기록이 두 개 생겼다. Google Site Kit에서는 이미 존재한다는 오류가 발생했다. Keycloak에서는 첫 시도가 취소된 뒤 인증 오류가 발생했고, Fluent UI에서는 폼 제출 동작 자체가 두 번 실행됐다.
