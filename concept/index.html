HOW TO START

잘 짜인 기획서가 없어도함께 정리하며 시작할 수 있고,소스가 없는 프로그램도새 코드로 다시 만들 수 있습니다.

아이디어, 기획서, 실행 중인 프로그램 가운데 지금 가진 것부터 확인합니다.

    상담한 팀 리더가
    배포까지 직접 책임집니다.

    01PLAN

    기능과 완료 기준을 먼저 잠급니다

    필수 기능, 제외 범위, 외부 연동과 완료 기준을 개발 전에 문서로 확정합니다.

    02CHECK

    화면과 동작을 먼저 맞춥니다

    핵심 화면과 주요 동작을 먼저 공유하고, 사용 흐름이 맞는지 확인한 뒤 본 개발에 들어갑니다.

    03BUILD

    자동화 테스트로 예외 조건까지 검증합니다

    주요 기능과 예외 조건을 반복 실행해 검증을 통과한 결과물만 배포합니다.

    04HANDOVER

    다음 개발이 가능한 상태로 넘깁니다

    소스 코드, 설정, 데이터 구조와 실행 방법을 전달하고 납품 범위에는 3개월 품질보증을 적용합니다.

    한 팀 리더가 끝까지상담부터 검수와 배포까지 같은 팀 리더가 책임집니다.
    범위와 기준은 문서로기능, 제외 범위와 완료 기준을 개발 전에 확정합니다.
    다음 개발이 가능한 인계소스, 설정, 데이터 구조와 실행 방법을 함께 전달합니다.
    AUTOMATED QUALITY TEST 오류는 납품 전에 끝냅니다.

    자체 자동화 테스트로 주요 기능과 예외 조건을 반복 검증합니다.

    검증을 통과한 결과물만 납품합니다.
    만약

    납품 범위에서 오류나 업데이트 문제가 발견될 경우, 3개월간 추가 비용 없이 바로잡습니다.
